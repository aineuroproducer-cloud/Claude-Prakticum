# Практикум «Claude: от новичка до ПРО»

Статический лендинг для Vercel.

- `index.html`, `styles.css`, `script.js` — главная страница. Ссылки на оплату и номер Яндекс.Метрики — в начале `script.js`.
- `oferta.html` собирается из `legal/oferta.md`: после правки текста запустите `python3 legal/build.py`.
- `privacy.html`, `consent.html`, `consent-ads.html` — политика и согласия.
